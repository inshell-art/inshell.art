# Inshell Mono 76 v1.0.0

This is the sealed, installable Mono 76 artifact. The repository-level README
describes the design history; this directory is the downstream source of
truth.

- 76 ordered records; 75 visible glyphs and metrics-only SPACE
- Regular 400
- 10-unit fixed advance
- 1.23-unit round centerline stroke
- deterministic IM76 on-chain payload
- private, Inshell-owned font software

Run `node ./verify.mjs` before integration. See `HANDOFF.md` for the full
contract.
